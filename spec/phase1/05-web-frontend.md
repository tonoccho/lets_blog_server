# 05. Web管理フロントエンド

## 目的

VSCode拡張が扱わない「管理系」機能(サイト登録、APIキー発行、投稿履歴、AIジョブ状況確認)を提供するWeb UIを実装する。

## 前提・決定事項

- 実装: TypeScript / Node.js + Tailwind CSS
- 役割: 管理画面(執筆・投稿はVSCode拡張側)
- 認証: Phase 1では個人利用前提のためログイン機能は必須としない(要再確認、[未決事項](#未決事項)参照)

## 画面構成(案)

| 画面 | 内容 |
|---|---|
| サイト一覧・登録 | WordPressサイトのURL/ユーザー名/アプリケーションパスワード登録 |
| APIキー管理 | クライアント用APIキーの発行・失効 |
| 投稿履歴 | `posts` テーブルの一覧(サイト別・ステータス別) |
| AIジョブ状況 | `generation_jobs` の一覧・詳細(Ollama/ComfyUIの実行ログ) |
| DB管理リンク | phpMyAdminへの導線 |
