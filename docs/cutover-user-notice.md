# カットオーバー利用者周知テンプレート

[docs/CUTOVER_RUNBOOK.md](CUTOVER_RUNBOOK.md) の「5. 既存ユーザーのKeycloak登録とパスワードリセット通知」から
参照される、利用者へ実際に送付するための周知文のテンプレート。実施日時・所要時間が確定した
時点で `<>` 部分を埋めて使用する。

Issue本文が要求する3点(全ユーザーがパスワード再設定を必要とすること / VSCode拡張の再ログインが
必要なこと / 切り替え中のダウンタイム見込み)を満たす内容にしてある。

---

## 事前告知(カットオーバー実施の24時間以上前に送付)

件名: 【重要】認証基盤切り替えのお知らせ(<実施予定日時>)

```
Let's Blog をご利用の皆様

認証基盤をKeycloak(OIDC)へ切り替えるメンテナンスを下記日程で実施します。
切り替え中は一時的にサービスを利用できません。

■ 実施日時
<YYYY-MM-DD HH:MM> 〜 <YYYY-MM-DD HH:MM>(想定ダウンタイム: 約<N>分)
※ docs/CUTOVER_RUNBOOK.md の実行記録に基づく実測見積もり。実施前の最終見積もりは
  リハーサル(バックアップのフェーズA)完了後に確定させ、本メールを更新して再送する。

■ 切り替え後、利用者に必要な対応
1. パスワードの再設定が必要です
   既存のパスワードはそのまま引き継がれません(パスワードの保存形式が新旧で異なるため)。
   切り替え完了後、登録済みのメールアドレス宛にパスワード再設定用のメールが届きます。
   メール内のリンクから新しいパスワードを設定してください。
   ※ 迷惑メールフォルダも確認してください。メールが届かない場合は管理者へご連絡ください。

2. VSCode拡張の再ログインが必要です
   コマンドパレット(Cmd/Ctrl+Shift+P)から「Let's Blog: Login」を実行し、
   表示されるコードをブラウザで入力して再度ログインしてください。
   これまでのAPIキー入力による認証は使用できなくなります。

3. Web管理画面のログイン方法が変わります
   従来のメールアドレス+パスワードの入力フォームの代わりに、Keycloakのログイン画面へ
   自動的に遷移します。上記1で再設定したパスワードでログインしてください。

■ 影響範囲
上記メンテナンス時間中は、Web管理画面・VSCode拡張からの記事投稿・画像生成・
サイト管理等、すべての操作ができません。既に公開済みの記事(WordPressサイト)の
閲覧には影響ありません。

■ 問い合わせ先
<連絡先>
```

```
https://<公開URL>

<連絡先> までご連絡ください。管理者側でパスワード再設定メールを再送できます。

```
